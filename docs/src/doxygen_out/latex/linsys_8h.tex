Solves the linear system as required by SCS at each iteration:\+      \[   \begin{bmatrix}
   (R_x + P) & A^\top \\
    A   &  -R_y \\
   \end{bmatrix} x = b
\]

for {\ttfamily x}, where {\ttfamily diag(\+R\+\_\+x, R\+\_\+y) = R}. Overwrites {\ttfamily b} with result.

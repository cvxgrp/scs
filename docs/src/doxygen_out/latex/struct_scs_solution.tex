\doxysubsection{Detailed Description}
Contains primal-\/dual solution arrays or a certificate of infeasibility. Check the exit flag to determine whether this contains a solution or a certificate. If when passed into SCS the members {\ttfamily \doxylink{struct_scs_solution_a655d98b6096451355a5d9862e854ad3e}{x}}, {\ttfamily \doxylink{struct_scs_solution_a26f3d210490a20299f493698658c5b2f}{y}}, {\ttfamily \doxylink{struct_scs_solution_ae104c406b1c56a37b7453be06193a1a7}{s}} are NULL then SCS will allocate memory for them which should be managed by the user to prevent memory leaks.

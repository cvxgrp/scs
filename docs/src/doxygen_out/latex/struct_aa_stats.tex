\doxysubsection{Detailed Description}
Lifetime diagnostics for an Anderson acceleration workspace.

Counters accumulate from aa\+\_\+init and are not cleared by aa\+\_\+reset, including internal resets after safeguard rejections. Rejection causes are split so a caller can tell what needs tuning.

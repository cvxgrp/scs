Initialize SCS and allocate memory.

All the inputs must be already allocated in memory before calling. After this function returns then the memory associated with {\ttfamily d}, {\ttfamily k}, and {\ttfamily stgs} can be freed as SCS maintains deep copies of these internally.

It performs:\+
\begin{DoxyItemize}
\item data and settings validation
\item problem data scaling
\item automatic parameters tuning (if enabled)
\item setup linear system solver:\+
\begin{DoxyItemize}
\item direct solver:\+ KKT matrix factorization is performed here
\item indirect solver:\+ KKT matrix preconditioning is performed here.
\end{DoxyItemize}
\end{DoxyItemize}
